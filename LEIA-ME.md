# 🚀 AutoZen - Início Rápido

## ⚡ Começar em 3 Passos

### 1️⃣ Instalar Dependências

**Opção A - Automático (Windows):**
```
📁 Duplo clique em: INSTALL.bat
```

**Opção B - Manual:**
```bash
npm install
```

### 2️⃣ Adicionar Logo (IMPORTANTE!)

1. Salve a logo como: `logo-autozen.png`
2. Coloque na pasta: `public/`

**Não tem a logo agora?** Não tem problema! O sistema vai funcionar mesmo assim (vai mostrar um erro de imagem no console, mas não quebra nada).

### 3️⃣ Rodar o Sistema

**Opção A - Automático (Windows):**
```
📁 Duplo clique em: START.bat
```

**Opção B - Manual:**
```bash
npm run dev
```

**Pronto!** Abra: `http://localhost:3000`

## 🆘 Problemas Comuns

### "Comando npm não encontrado"
**Solução:** Instale o Node.js em: https://nodejs.org/

### "Porta 3000 já está em uso"
**Solução:** Rode em outra porta:
```bash
npm run dev -- -p 3001
```

### "Logo não aparece"
**Solução:** 
1. Verifique se o arquivo está em `public/logo-autozen.png`
2. Veja instruções completas em `IMPORTANTE_LOGO.md`
3. Ou use a versão sem logo temporariamente
